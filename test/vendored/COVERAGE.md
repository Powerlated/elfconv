# Vendored i386 oracle coverage

This is an inventory of candidate oracle coverage, not evidence of successful execution. **No candidates below have been verified in this integration.** A candidate becomes executed coverage only after its native/lifted (or explicitly specified browser) CTest run succeeds in the configured environment; this map does not record such success.

| Slice | Pin / candidate tests | Candidate behavior | Execution mode and important limits |
|---|---|---|---|
| glibc public libc | glibc `b72fcafcc9d307790bd24ebba65f52994ca5598e`; `i386_glibc_sscanf`, `i386_glibc_sprintf`, `i386_glibc_mbrtowc` | Scanf conversions/return counts/malformed inputs; sprintf formatting and multibyte precision; restartable UTF-8 mbrtowc state and invalid terminators. Details and locale caveats: `glibc/libc/COVERAGE.txt`. | Candidate native-vs-lifted via `run_i386.py`; locale-dependent branches may require installed locales. C23 scanf binary-prefix behavior is not covered. |

Details: `glibc/loader/README`. | Candidate native-vs-lifted i386 `-O2`; does not cover signal masks, FPU/register preservation, or unwind/backtrace behavior. |

The i386 CMake scope conditionally adds each slice directory when its `CMakeLists.txt` is present. That makes registration available when a slice is present; it does not imply the option-gated pthread browser tests or SDL prerequisites were enabled or met. See each slice's coverage map for source functions, adaptations, dependencies, and further gaps. Vendored source pins and retained upstream license notices are documented in the slice files; no success or support claim is inferred from registration alone.
