Vendored i386 test entry and coverage

Registration: test/vendored/CMakeLists.txt is the sole entry, included by test/elfconv/i386/CMakeLists.txt after its toolchain discovery. It requires the checked-in glibc libc, loader, filesystem, pthread, and SDL2 slice CMake files; no presence-based skips. CTest retains native-vs-lifted run_i386.py tests. Names: i386_glibc_sscanf, i386_glibc_sprintf, i386_glibc_mbrtowc, i386_glibc_setjmp, i386_glibc_preadvwritev, and i386_sdl2_surface_pixels. Browser pthread tests i386_glibc_pthread_tsd3/tsd4 are opt-in via ELFCONV_GLIBC_PTHREAD_BROWSER_TESTS=ON; they require Python 3.11, installed Playwright Chromium, Emscripten pthread/JSPI, cross-origin isolation and SharedArrayBuffer. Node alone is not a pthread oracle. SDL2 builds pinned release 2.30.11 commit fa24d868ac2f8fd558e4e914c9863411245db8fd as an ALL prerequisite, using GCC -m32 and upstream SDL2_test.

Configure the repository with ELFCONV_ARCH=x86 and ELFCONV_I386_TESTS=ON; normal i386 tool discovery requires GCC, Node, objcopy and em++. Build and run the normal lane with `cmake --build <build> --target elflift` and `ctest --test-dir <build> -R '^i386_(glibc_|sdl2_)' --output-on-failure`. SDL acquisition additionally requires Git/network access and the SDL build's host dependencies. For the browser lane, install with `npm install --prefix test/browser` and `npx --prefix test/browser playwright install chromium`, configure the opt-in, build elflift, then run `ctest --test-dir <build> -R '^i386_glibc_pthread_' --output-on-failure`.

Optional locale isolation: create local locales with `mkdir -p <build>/vendored-locales`; `localedef --no-archive -i de_DE -f UTF-8 <build>/vendored-locales/de_DE.UTF-8`; `localedef --no-archive -i en_US -f ISO-8859-1 <build>/vendored-locales/en_US.ISO-8859-1`; configure `-DELFCONV_GLIBC_LOCALE_PATH=<build>/vendored-locales`. CTest sets LOCPATH. mbrtowc requires C.UTF-8 or C.utf8. Never assume system locales are present.

Evidence (observed in the integrated worktree): native i386 sscanf (locale cases provisioned), sprintf, mbrtowc, setjmp, preadv/pwritev passed. Lifted attempts for glibc oracles failed compiling the existing import runtime and did not reach guest execution; notably I386LocaleExtra.inc has void-pointer subtraction and shadowed mbstate state, and I386PosixExtra.inc has an unterminated conditional. Do not report lifted passes. SDL's pinned dependency build succeeded; its native and lifted results are those reported by the SDL slice owner, not assumed here.

Coverage limits and provenance: glibc libc pin b72fcafcc9d307790bd24ebba65f52994ca5598e; loader glibc 2.39 ef321e23c20eebc6d6fb4044425c00e6df27b05f; filesystem glibc 2.40 peeled commit 3d1aed874918c466a4477af1da35983ab036690e; pthread glibc 04e750e75b73957cf1c791535a3f4319534a52fc; SDL pin above. Original upstream license notices and COPYING files remain with slices. Detailed slice source/adaptation maps remain in libc/COVERAGE.txt and filesystem/COVERAGE. Loader exercises setjmp continuation only, not signal masks/FPU/unwind. Filesystem compares vectored I/O lengths/bytes, but its identical extents cannot distinguish duplicated or swapped data. Pthread covers TSD isolation/destructor iterations only, not detach/attributes/condition waits/cancellation. SDL covers selected pixel/surface behavior; upstream-disabled cases and padded-pitch/partial clipping, audio/events/video/renderer/syswm/GL remain uncovered. GBE test inspection found no equivalent Steam callback oracle; existing test/elfconv/i386/steam-main.cpp and run_steam.py retained, not exercised here; real audio providers and compatible i386 C++ runtimes remain prerequisites.
